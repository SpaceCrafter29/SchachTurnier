❓ FAQ

Warum brauche ich Replit?
WhatsApp Web braucht einen Browser. Replit ist kostenlos und läuft im Browser - perfekt!
Kostet das etwas?
Nein! Replit kostenlos, Google Cloud kostenlos (300$ Guthaben). Insgesamt kostenlos!
Wie lange läuft der Bot?
Auf Cloud Run: 24/7 ohne Unterbrechung. Der Bot sendet täglich ab 20:00 Uhr Nachrichten.
Kann ich den Bot anpassen?
Ja! NOTIFICATION_HOUR und NOTIFICATIONS_PER_DAY in der .env Datei ändern.
